# Escudo

Archivos originales del escudo comunal; úsalos siempre desde aquí, nunca desde capturas.

- `escudo-color.png` — versión principal, a todo color, sobre fondos claros (`blanco`, `marfil-institucional`).
- `escudo-mono-azul.png` — una tinta `azul-institucional` (#174A6E), para impresión a una tinta.
- `escudo-mono-negro.png` — una tinta negra.
- `escudo-negativo.png` — blanco sobre transparente, para `azul-institucional` y fondos oscuros.

Mínimo: 15 mm / 48 px de alto. Resguardo: 1x por lado (x = ¼ del alto del identificador horizontal). No deformar, recolorear, rotar ni agregar efectos.
