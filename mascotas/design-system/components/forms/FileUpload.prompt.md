Drop zone + file list for trámite documents; always state accepted formats and max size.

```jsx
<FileUpload label="Cédula de identidad" files={[{name:'cedula-frente.jpg',size:'1,2 MB'}]} />
```

See FileUpload.d.ts for all props. Styling lives in components/hds.css (hds- classes) and resolves to tokens in tokens/*.css.
