# AsiSiAsiNo

Par de tarjetas que compara un mensaje correcto con uno incorrecto para el mismo caso.

- Fila: etiqueta del caso (`titulo-bloque`, `azul-institucional`, 220 px), luego `.mh-asi.mh-asi--si` y `.mh-asi.mh-asi--no`, cada una con `<b>` (veredicto) y `<p>` (el mensaje entre comillas tipográficas “ ”).
- El veredicto siempre lleva su signo y su palabra: «✓ Así sí» en `verde-territorio`, «✕ Así no» en `terracota`. El color nunca va solo.
- `terracota` sobre blanco es 4,2:1: mantén el veredicto en `veredicto` (24 px Bold); no lo uses para textos menores.
- Va sobre `marfil-institucional`; el ejemplo correcto sigue las cuatro preguntas (qué ocurrió, a quién afecta, qué debe hacer, dónde pedir ayuda).
