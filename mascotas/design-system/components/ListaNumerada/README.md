# ListaNumerada

Pasos o puntos ordenados con un disco numerado; tres variantes según el fondo y la densidad.

- **Tarjeta** (`.mh-numerada-grilla` > `.mh-numerada-tarjeta`): grilla de 3 columnas, `espacio-6` de separación, disco `.mh-disco--tarjeta` de 64 px `azul-institucional` con número `marfil-institucional`, texto `texto-destacado`. Sobre `marfil-institucional`. Para objetivos o listas de 3 a 6 ideas.
- **Fila** (`.mh-numerada-fila`): disco `.mh-disco--fila` de 56 px `verde-territorio` con número `blanco`, título de 380 px y descripción; filetes de 2 px `gris-claro` arriba y abajo. Sobre `blanco`. Para pasos con explicación, como las cuatro preguntas de cada mensaje.
- **Sobre azul** (`.mh-numerada-azul`): disco `.mh-disco--azul` de 52 px `celeste-rio` con número `gris-texto` (nunca blanco), texto `marfil-institucional`, filete `azul-filete`. Dentro de `.mh-sobre-azul`.
- El consumidor da el número dentro del disco; empieza en 1 y no salta.
