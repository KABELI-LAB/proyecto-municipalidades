Mobile app bottom navigation, 3–5 destinations, always icon + label.

```jsx
<BottomNav value="inicio" items={[{id:'inicio',label:'Inicio',icon:'house'},{id:'tramites',label:'Trámites',icon:'file-text'}]} />
```

See BottomNav.d.ts for all props. Styling lives in components/hds.css (hds- classes) and resolves to tokens in tokens/*.css.
