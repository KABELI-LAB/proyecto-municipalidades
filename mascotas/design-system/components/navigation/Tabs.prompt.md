Underline tabs for switching views of the same content (e.g. Requisitos / Paso a paso / Contacto).

```jsx
<Tabs items={[{id:'req',label:'Requisitos'},{id:'pasos',label:'Paso a paso'}]} />
```

See Tabs.d.ts for all props. Styling lives in components/hds.css (hds- classes) and resolves to tokens in tokens/*.css.
