Quick-access tile for the "¿Qué necesitas hacer?" grid — icon, need-based label, optional hint.

```jsx
<ServiceTile icon="file-text" label="Trámites" hint="Certificados, permisos, patentes" />
```

See ServiceTile.d.ts for all props. Styling lives in components/hds.css (hds- classes) and resolves to tokens in tokens/*.css.
