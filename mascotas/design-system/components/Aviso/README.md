# Aviso

Tarjeta blanca con un ícono de 48 px y una regla o advertencia breve, con las palabras clave en negrita.

- `.mh-aviso` > `<svg>` (48 × 48, trazo `azul-institucional`) + `<div>` con el texto en `texto-bloque`; resalta con `<b>` solo las palabras clave.
- Va sobre `marfil-institucional`, en filas de dos con `espacio-8` de separación.
- Los íconos de la vista previa son provisorios: el municipio aún no define su set de íconos (ver Iconografía).
- No: fondos de color en el aviso; la tarjeta es blanca y el mensaje se apoya en el texto.
