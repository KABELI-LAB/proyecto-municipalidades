# @muni/design-system

Tokens del design system **Muni Hualañé**, tomados del deck https://claude.ai/artifact/TxpyLvmaGCim3LSdBo61LF (fuente: Manual de Imagen Corporativa, borrador octubre 2026, paleta preliminar).

- `tokens.json`: fuente de verdad, con usos y ratios de contraste de cada color
- `tokens.css`: variables `--muni-*` y fuentes (Montserrat para títulos, Source Sans 3 para texto)
- `base.css`: reset y tipografía base; solo para la app anfitriona o los dev servers

## Reglas rápidas

| Color | Uso | Texto encima |
|---|---|---|
| Azul `#174A6E` (~45 %) | Principal, títulos, fondos | blanco o marfil |
| Verde `#4E7D52` (~15 %) | Acentos, territorio | blanco |
| Marfil `#F5F1E8` / blanco / grises (~30 %) | Fondos | gris-texto o azul |
| Celeste `#6BA8B8` | Trámites, información | **solo gris-texto** |
| Terracota `#B96545` | Cultura, patrimonio | blanco solo grande/negrita |
| Amarillo `#E5B84B` | Alertas, llamados | **gris-texto o azul, nunca blanco** |

Radios de 3–4px. Como máximo dos familias tipográficas por pieza.
