# UI kit — app

App municipal móvil dentro de un marco iOS (ios-frame.jsx). Screens.jsx contiene Inicio, Trámites, Solicitud, Avisos, Asistente, Perfil. El teléfono izquierdo es interactivo; los otros muestran dark y alto contraste.

Compone los componentes de `window.HualaDesignSystem_c0b80f` (cargados desde `../../_ds_bundle.js`). No hay producto existente que replicar: es la propuesta de referencia del sistema.
